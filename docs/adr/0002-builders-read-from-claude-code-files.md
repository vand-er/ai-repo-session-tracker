# Builders are read from Claude Code's own files, not from a hook

The Board shows which Builder is working each Ticket, its Activity, and when it is Finished. We read these from the files Claude Code already writes, which are appended live: an orchestrator's `subagents\agent-<id>.meta.json` names the Ticket at launch (e.g. "Build ticket 11") and gains `"finished": true` when the Builder hands back, and the transcript's tail gives the latest action. We considered a Claude Code hook (SubagentStart, PostToolUse, SubagentStop) writing an event file for the Board. We rejected it for now: it needs setting up per machine or repo, and the files already meet the 15-second tick with about a second to spare. The cost is that `meta.json` and the transcript layout are Claude Code internals, not a documented interface; if an update breaks them, a hook is the fallback, and the Progress file's own `finished` line covers Finished without either.
